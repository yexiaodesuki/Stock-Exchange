# 当前版本验收

2026-11-26，业务基线 `1ed4c1a` 加本次验收改动（未提交）。本机为 Windows、Temurin 17.0.18、Maven 3.9.16、Node.js 24.16 和 PowerShell 7。

## 无容器回归（也是 CI 入口）

```powershell
pwsh -NoProfile -File build/securities/verify-current.ps1
```

依赖已缓存时可加 `-Offline`。GitHub Actions 使用 Windows、JDK 17 和 Node.js 24，在 push、PR、手动触发时执行该入口，上传 Maven XML 报告。工作流为本次新增，尚未推送执行。默认清除进程继承的实服务测试开关，不读本地模型配置或启动容器；本命令会重建 Maven 的 target 目录，请勿与同一工作区其他构建同时执行。

本机以 `-Offline` 实测：Java 116 条记录，101 通过、15 条条件跳过、0 失败；前端逻辑 6 项通过，启动/停止脚本隔离检查 18/8 组通过。跳过的项目是实际依赖相关测试和需要显式开启的基准，脚本会逐项打印；“无容器回归通过”不是“全部通过”。

## 隔离联调

按 [运行说明](running.md) 配置 Docker Desktop 与本地模板，启动本项目的健康 MySQL、Redis、Kafka，安装浏览器测试依赖（`npm --prefix ui ci`，Windows 默认使用 Edge）。在仓库根目录运行：

```powershell
pwsh -NoProfile -File build/securities/verify-current.ps1 -Integration
```

入口复用既有网关联调：生成随机测试库及测试命名空间，启动临时配置中心、业务进程和网关，使用假生成器而非付费接口。若本机 BGE 与 Chroma 就绪，另跑真实本地向量检索；否则会明确跳过。正式账户与数据卷不作为测试数据。

本机使用已启动的项目容器实测：Java 141 条记录，139 通过、2 条跳过、0 失败；跳过的是直连开发库的旧入口和独立性能用例。前端 6 项、嵌入服务纯逻辑 3 项、启停脚本 26 组通过。通过范围包括 V1–V5 空测试库迁移、成交及撤单、引擎强制终止恢复、浏览器网关交易和入金幂等、演示账户初始化续跑，以及本地 BGE＋Chroma 检索。外部聊天与嵌入用模拟契约测试，不代表供应商实测。

## 边界

没有验证另一台全新电脑从克隆到空卷冷启动；临时空数据库迁移不等于全新 Docker 数据卷验收。未验收真实外部模型、跨平台启动、生产高可用或公开部署。性能测试独立执行，见 [性能基线](performance.md)。
