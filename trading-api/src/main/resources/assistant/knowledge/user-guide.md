# 操作指南

## 注册与登录 | 注册,登录,登陆,新用户,创建账户
在登录页选择注册，填写邮箱、显示名称和密码后登录。新注册账户不会自动获得模拟资金或股票；可从交易页的模拟入金入口增加 USD，再按实际盘口下单。演示账户属于初始化数据，不代表所有新账户都会自动配资。助手不会查询密码、重置密码或代替你登录。

## 交易页与账户 | 如何下单,怎么下单,如何买入,怎么买入,如何卖出,怎么卖出,选择股票,切换证券,如何查看账户
登录后，页面顶部选择证券；USD 是不同证券共用的资金账户，持仓和订单按证券区分。委托区域选择买入或卖出、限价和整数股数，提交后等待最终结果。活动订单看剩余股数；历史订单看最终状态。卖出需要已有可用持仓，入金不会赠送股票。助手可以解释数据和操作步骤，但不会替你提交委托。

## WebSocket 与页面刷新 | websocket,推送,连接中断,连接断开,重连,刷新页面
WebSocket 用于推送交易和行情更新，不是资产的持久存储。短暂断线时页面会尝试重连并重新读取权威查询；连接状态不代表某笔订单一定成交。不要因为连接中断而重复入金或重复下单。持续断线先检查页面连接提示和服务状态，助手不能仅凭断线信息判断后台具体故障。

## 退出、会话与账户显示 | 退出登录,退出账户,登录过期,会话过期,会话校验,全部持仓,可用和冻结,可用与冻结
点击右上角“退出登录”结束当前页面会话，不会撤销已提交的委托。登录过期请重新登录，提示会话校验失败时先刷新页面。“全部持仓与资金”用于核对不同证券的持仓及共享 USD 账户；可用部分可用于新委托，冻结部分不能再次使用。页面显示暂不可用时，不要把空白或旧数据理解为余额为零。

## 核对提交结果与请求进度 | 请求进度,下单超时,提交超时,撤单超时,未确认,重复下单,订单去哪了,提交结果
提交委托或撤单后先查看“请求进度”。请求等待确认、连接中断或超时都不等于操作失败，也不代表委托已成交。页面刷新后可继续查询同一会话内保存的未决请求；回到相同证券，通过“当前委托”和“历史委托”核对最终结果。不要为确认结果再提交一笔相同委托；如果服务暂不可用，先等待恢复再刷新查询。

## 当前委托、历史委托与本人明细 | 当前委托,历史委托,历史订单,成交明细,刷新历史,剩余股数,订单状态
先选择证券。“当前委托”列出仍活动的委托，剩余股数是尚未成交的数量；点击该行“撤单”并等待确认。“历史委托”用于查看已结束的委托，可以点“刷新历史”。在对应历史委托行点“成交明细”，下方显示本人的成交方向、价格、数量和时间。撤销剩余部分不会撤销先前成交；没有成交的委托不会有成交明细。“最近成交”是市场成交，不等于本人的成交明细。

## 只读助手、行情摘要与引用 | 只读助手,交易助手,怎么用助手,回答出处,怎么看引用,模型降级,检索原文,行情时间范围
登录后展开“只读交易助手”，可询问本人资金、冻结、订单、入金，也可问公开行情与系统操作。证券可用名称、简称或英文代码。行情摘要支持最近 1 小时、24 小时或 7 天的滚动窗口，不按交易日或任意日期统计；图表周期与摘要时间范围不同。知识回答可以展开引用核对原文；显示“检索原文”或“回退”时，不代表外部模型已成功生成。助手不执行交易、不预测价格，请勿输入密码、密钥等隐私。
