# 模拟入金

## 入金入口与额度 | 如何入金,怎么入金,如何充值,怎么充值,怎样充值,怎样入金,哪里充值,哪里入金,在哪充值,在哪入金,充值入口,入金入口,入金额度,充值额度,充值限制,入金限制,入金上限,充值上限
登录交易页点击“模拟入金 / 入金记录”，填写 USD 金额后提交，并在记录中查看最终状态。当前模拟入金{depositEnabled}，单笔范围 {depositMinimum}～{depositMaximum} USD，每用户每日累计上限 {depositDaily} USD，按 UTC 日界线计算，待确认申请也占额度。这只是模拟 USD，不连接银行卡或支付渠道，也不会给账户赠送证券。助手仅解释，不执行入金。

## 申请状态与重复提交 | pending,succeeded,rejected,待确认,入金状态含义,入金状态什么意思,充值状态含义,重复入金,重复充值,入金没到账,充值没到账
PENDING 是尚未确认，不代表失败，也不能据此承诺到账时间；SUCCEEDED 表示已确认模拟资金入账；REJECTED 表示明确拒绝，应查看拒绝原因。响应丢失或待确认时应保留原申请，不能换一个新申请来“补发”，否则可能形成两笔不同入金。页面刷新会尝试恢复原申请查询，服务端已受理的申请会继续处理；初始演示配资不属于此入口的入金申请。查询个人记录请问“我的入金情况”。
